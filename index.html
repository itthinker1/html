// 01 · 共鸣式编程

vibe coding 是什么？

一种「跟着感觉走」的创作方式——把你的想法说清楚，剩下的交给 AI 与你的迭代。

vibe coding 是近期兴起的一种编程方式：用自然语言描述创意与需求，由 AI 辅助生成代码，通过直觉与迭代让想法快速变成可运行的东西。

它不要求你先把一切想清楚、不要求你记忆所有语法。重点是降低门槛——把「想」和「做」之间的鸿沟，用对话一点点填平。

常见的节奏是：说出一个点子 → 看它跑起来 → 不满意就接着说。像聊天一样写代码，像雕刻一样打磨。

// 04 · 为什么是现在

为什么 vibe coding 让人上瘾

不是「写代码变得不重要」，而是「动手变得足够便宜」——于是万物皆可造。

零门槛上手

说出想法就能开始，不用先成为「程序员」。直觉第一，术语靠边。

灵感即时落地

趁热打铁。从「一闪而过」到「能跑的东西」，中间不设关卡。

迭代即乐趣

每次「再调一下」都有即时反馈，改着改着，东西就变成了你想要的。

低成本试错

构想的成本几乎为零。多走几步岔路也没关系，因为每一步都很便宜。

随时随地

通勤路上、深夜客厅、咖啡桌边——只要一个想法，就能开始创作。

边做边学

在真实项目里理解代码。看 AI 怎么改，你就在潜移默化中学会了怎么读。
